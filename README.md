# Análises de ativos financeiros e índices de mercado

Este repositório contém scripts em **R** para análise de desempenho de ativos financeiros e índices de mercado.

## Estrutura do Repositório

-   `data/` → Bases de dados utilizadas
-   `scripts/` → Códigos para análise
-   `output/` → Gráficos e relatórios

## Principais Análises

-   Desempenho de índices offshore e onshore

-   Desempenho de fundos de investimento

-   Balanço de empresas

-   Curvas de juros

-   Fluxo de investidores da B3
